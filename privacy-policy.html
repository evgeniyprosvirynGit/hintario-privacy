Hintario Privacy Policy

Effective date: October 19, 2026

Hintario translates text that you select on a web page and displays the result beside that text. This policy describes the data Hintario handles, where it goes, and how you can remove it.

Data sent to translation providers

When you request a translation, Hintario sends the selected text, source and target languages, and, for a single word, a short phrase around it (up to 12 words) to translation providers over HTTPS. If a provider fails or limits a request, Hintario may send the text to another provider.

Data stored in Chrome

To show and restore hints, Hintario stores translation history in Chrome's local extension storage. A history record may contain the selected text, its translation, a short excerpt before and after the selection, the page origin and path, an embedded frame location, the hint style, and the time it was created. History stays in this Chrome profile and is not sent to Hintario's developer.

You can review and remove a site's history or clear all history from the History tab in Hintario settings. You can also delete an individual hint on the page. Uninstalling Hintario removes its extension storage through Chrome.

Language, interface language, keyboard shortcut, and selection icon preferences use Chrome's sync storage and may sync through your Chrome profile. Hint styles and optional provider API keys are stored locally in the browser and are not synced. Provider API keys are sent only to their corresponding provider when you request a translation.

Hintario keeps up to the 30 most recent translation diagnostic records in local extension storage for troubleshooting. They contain timestamps, language pairs, browser and extension versions, provider identifiers, request durations, and error categories. They never contain selected text, translations, page addresses, or API keys. The records stay on this device, are replaced by newer entries, and are not sent to the developer.

Site access and permissions

Hintario runs on pages you visit so it can respond to a selected phrase and restore saved hints, including inside embedded reading frames. Page text is read locally only as needed to locate the selected phrase and position the hint. Hintario does not send general page contents, browsing history, or page addresses to its developer.

The extension requests scripting to operate in accessible page frames, storage for preferences and hint history, and HTTP/HTTPS site access to restore hints, associate them with the correct page, and work in embedded reader frames. See the Chrome Web Store listing for the full permission justifications.

Tracking and data sharing

Hintario contains no analytics, advertising, tracking pixels, or developer-operated translation server. It does not sell user data. Translation text may be sent to more than one provider if a request needs another attempt.

Chrome Web Store Limited Use

Hintario's use of data received through Chrome APIs is limited to providing its disclosed single purpose and complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
